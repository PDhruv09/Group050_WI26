# Research Modules

This document preserves the new research direction as implementation modules.

## 1. Behavioral Evolution Over Time

Analyze how interaction patterns change across time, including conversationality, sophistication, emotional dependence, and shifts from productivity to companionship.

## 2. Tool vs Social Entity Transition

Classify interaction mode as tool, assistant, collaborator, companion, or therapist-surrogate.

## 3. Emotional Analysis

Move beyond positive/negative sentiment into sadness, loneliness, fear, vulnerability, joy, confusion, dependency, frustration, and affection.

## 4. Human Cognitive Outsourcing

Measure what mental tasks users outsource to AI, including writing, coding, studying, decision-making, emotional regulation, and life planning.

## 5. Prompt Sophistication Evolution

Track prompt length, lexical complexity, instruction specificity, role prompting, and other prompt-engineering behaviors.

## 6. User Archetype Discovery

Cluster users into behavioral groups using embedding and behavioral metadata.

## 7. Conversation Depth Analysis

Measure turn depth, chaining, self-disclosure, topic persistence, and interaction duration.

## 8. Semantic Evolution and Drift

Use embedding-based topic modeling and semantic trajectories to track how topics evolve.

## 9. Network Analysis

Build graphs connecting emotions, topics, behavioral states, and transitions.

## 10. Event-Driven Cultural Analysis

Analyze how major external events affected prompt behavior and emotional volatility.
